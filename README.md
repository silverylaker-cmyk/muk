# 묵찌빠 카메라 게임

휴대폰 전면 카메라로 손 모양(묵·찌·빠)을 인식해 컴퓨터와 묵찌빠를 하는 모바일 웹앱입니다.
카운트("가위 바위 보!", "묵 찌 빠!")는 브라우저 음성 합성(TTS)으로 읽어 주며, 마지막 박자에 낸 손을 판정합니다.

## 실행
정적 파일이므로 아무 HTTPS 호스팅에 올리면 됩니다(카메라·음성은 HTTPS 필수).
- GitHub Pages: 저장소 Settings → Pages → Source를 **GitHub Actions**로 두면 `.github/workflows/pages.yml`이 자동 배포합니다.
- 로컬 테스트: `npx serve .` 후 `http://localhost:3000` (localhost는 HTTP 허용).

## 구조
| 파일 | 역할 |
|---|---|
| `gesture.js` | MediaPipe Hands 21개 랜드마크 → 묵/찌/빠 분류 + 프레임 다수결 안정화 |
| `app.js` | 카메라, 인식 루프, 음성 카운트, 게임 규칙 |
| `index.html`, `style.css` | 모바일 UI |
| `test/gesture.test.js` | 분류기 단위 테스트 (`npm test`) |

## 인식 방식
- 손가락별 "펴짐 점수"를 손목 기준 거리 비율과 관절 각도로 계산합니다. 회전·기울기·좌우 반전에 영향받지 않습니다.
- 묵 = 검지~소지 모두 접힘, 빠 = 모두 펴짐, 찌 = 검지+중지(또는 엄지+검지) 펴짐. 그 외는 "인식 안 됨"으로 두고 재시도합니다.
- 최근 7프레임 다수결로 떨림을 제거하고, 판정 순간에는 약 0.65초 동안의 결과를 신뢰도 가중 합산합니다.

## 규칙
1. 가위바위보로 공격권을 정합니다.
2. 공격자가 부른 손과 상대 손이 **같으면 공격자 승리**.
3. 다르면 가위바위보 승자가 새 공격자가 되어 2로 돌아갑니다.
